Common questions

When should I use this kit?

Preview the plan once, then use the First-Then-Next board any time you need to leave — it works for any outing, not just one specific trip.

Is this kit specific to one destination?

No — this kit covers the transition of leaving itself (shoes, coats, gathering things, stopping what you're doing), so it works no matter where you're headed.
